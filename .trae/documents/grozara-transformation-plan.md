# Grozara Website Transformation Plan

## Overview

Transform the current "Pocket" investment app website into "Grozara" - a smart grocery list app website.

## Key Changes Required

### 1. Hero Section (`src/components/Hero.tsx`)

* **Current**: "Invest at the perfect time" with investment-focused messaging

* **New**: "Shop smarter, not harder" with grocery list management focus

* Update main headline and description to highlight smart grocery features

* Keep the phone demo but update context

### 2. Primary Features (`src/components/PrimaryFeatures.tsx`)

**Current Features** (Investment-focused):

* Invite friends for better returns

* Notifications on stock dips

* Invest what you want

**New Features** (Grocery-focused):

* Smart List Management - Create and organize multiple grocery lists with quantities

* Reward Cards Management - Store and scan loyalty cards with barcode support

* Mobile-First Experience - Optimized touch interactions for iOS and Android

### 3. Secondary Features (`src/components/SecondaryFeatures.tsx`)

**Current Features** (Investment-focused):

* Invest any amount

* Build a balanced portfolio

* Trade in real-time

* Profit from your network

* Encrypted and anonymized

* Portfolio tracking

**New Features** (Grocery-focused):

* Add items with quantities

* Organize items in categories

* Mark items as completed

* Search and filter functionality

* Barcode scanning for cards

* Beautiful modern design

### 4. Reviews Section (`src/components/Reviews.tsx`)

* **Current**: "Everyone is changing their life with Pocket" + investment testimonials

* **New**: "Everyone loves shopping with Grozara" + grocery shopping testimonials

* Update review content to focus on grocery shopping experiences

### 5. Call to Action (`src/components/CallToAction.tsx`)

* **Current**: "Get your first tips today" with investment focus

* **New**: "Start shopping smarter today" with grocery app focus

### 6. README.md

* **Current**: "Pocket" branding and investment app description

* **New**: "Grozara" branding and grocery list app description

### 7. Global Brand Updates

* Replace all "Pocket" references with "Grozara"

* Update meta descriptions and titles

* Maintain existing design system and color scheme

## Implementation Order

1. README.md (foundational branding)
2. Hero.tsx (main landing experience)
3. PrimaryFeatures.tsx (core value proposition)
4. SecondaryFeatures.tsx (detailed features)
5. Reviews.tsx (social proof)
6. CallToAction.tsx (conversion)

## Content Themes

* **Smart**: Intelligent grocery list management

* **Convenient**: Easy-to-use mobile experience

* **Organized**: Better shopping organization

* **Modern**: Beautiful, clean interface

* **Efficient**: Save time and money shopping
