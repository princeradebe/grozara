# Grozara website

The landing page for Grozara, an iPhone app for South African shoppers: lists, loyalty cards and
Boyfriend Mode. A scroll-driven story through animated worlds, guided by Zara, a 3D mascot.

- `pnpm install`, then `pnpm dev` (http://localhost:3000)
- `pnpm build` before shipping

The creative direction, feature claims and architecture are in [docs/DESIGN_BRIEF.md](docs/DESIGN_BRIEF.md);
agent rules are in [AGENTS.md](AGENTS.md).
